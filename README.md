# 🚀 Desafio CSPTech

Repositório de testes automatizados para a aplicação TodoMVC (React) usando Cypress como ferramenta principal.

## 📌 Funcionalidades Testadas

- ✅ Criação de novas tarefas
- ✅ Edição de tarefas existentes
- ✅ Exclusão de tarefa existente
- ✅ Persistência de dados

## 🛠️ Tecnologias Utilizadas

- **Cypress** v12.0+
- **JavaScript** (ES6+)
- **GitHub Actions** (CI/CD)
- **Mochawesome** (Relatórios)

## 💻 Como Executar os Testes

1. Clone o repositório e instale as dependências:
```bash
   git clone https://github.com/allandxsh/desafio-csptech-todo.git
   cd desafio-csptech-todo
   npm install
```

2. Rode o projeto com Cypress:
```bash
   npx cypress open
   npx cypress run
